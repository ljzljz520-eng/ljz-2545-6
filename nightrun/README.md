# 🌃 江湾夜跑（nightrun）

城市夜跑主题站：移动首页突出**路线筛选**；筛选同时考虑距离、坡度、
**带观察时刻与覆盖范围的照明记录**、以及补给点营业时段。
空间数据库（SQLite + R\*Tree）管理路线分段、几何版本与观察版本；
网页可保存收藏、集合点与退出点，离线编辑后按字段合并。

> 界面与 API 只呈现**可核查的观察记录**，**不承诺安全**。
> “照明良好”表示在给定观察时刻、由近期夜间观察覆盖的路段点亮；
> 白天照片只证明灯具存在，不能当作夜间保证。

## 运行

```bash
npm install
npm start                 # http://localhost:3000 （首次启动自动播种 data/nightrun.db）
npm test                  # 五个验收场景（内存库，固定时间，可重复）
npm run benchmark         # 预分段 R*Tree 索引 vs 实时空间求交
npm run sync-shared       # server/geo.js → public/js/geo.js（唯一事实源）
```

## 关键约束（对应需求）

- 距离 / 坡度 / 交叉点 / 最近投影全部由服务端从**原几何**计算；
  Douglas–Peucker 简化线**只用于展示**，缩放/换公差不改变任何判断。
- 照明：只采纳 180 天内、当前处于其声明时段的夜间实访/跑友上报；
  白天照片永不作夜证；亮/暗覆盖冲突给出桩号区间与证据清单。
- 几何版本（`geom_version`）与观察版本（`obs_version`）分离；
  旧线路可继续收藏，公共更新不覆盖个人集合点。
- 个人集合点离线编辑走字段级 LWW + 墓碑删除；公共路线/公共注意是独立只读通道。
- 定位权限拒绝/超时/不支持时提供**手动经纬度入口**，与 GPS 同一判定路径。
- 跨桥最近点逐线段投影，桥与岸线不会因包围盒接近而误配。

## 目录

```
server/geo.js    共享几何/时间判定（UMD，浏览器同源复制到 public/js/geo.js）
server/db.js     SQLite schema、R*Tree 分段、版本、观察、字段级合并
server/seed.js   虚构城市江湾市（跨桥/冲突/过期/白天照片/旧线路/补给时段）
server/api.js    筛选、详情、最近投影、提示、观察上报、基准、集合同步
public/          移动优先前端（无外部依赖，SVG 自绘地图）
test/            五个验收场景
docs/            ALGORITHMS（可核查算法）、ACCEPTANCE（验收手册）、DESIGN（原创设计）
scripts/         空间策略基准、共享模块同步
```
